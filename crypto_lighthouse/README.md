# Lighthouse Crypto

独立加密灯塔服务，不依赖库存灯塔。

## 核心原则
- 证据先行 · 中期为主 · 统计验证 · 不造数据
- Binance / OKX / Coinbase 现货分别取证；单源失败不拖垮其他源
- Binance Futures 接入 OI、Funding、强平事件等衍生品证据
- BTC 可接入公开 Farside ETF 净流量；FRED 宏观层可用则显示
- 15 个主要加密资产每轮扫描；Top 3 按真实趋势评分动态排序
- 后端每 60 秒完整扫描；手机页面每 30 秒读取结果
- 实时价格与历史统计严格分层，不用历史收盘价冒充实时价格

## 历史统计
- 使用真实已完成 UTC 日线，不把当天未完结 K 线混入历史相似样本
- 相似条件包含 7 日走势、30 日走势、成交量状态
- 输出 1/3/7/30/90 日上涨/下跌频率、中位收益、最好/最差收益、样本数
- 输出当前价格过去 90 日最大回撤
- 输出历史相似条件样本的 90 日最差路径回撤
- 相似样本少于 20 时不显示统计概率；不会把趋势评分伪装成历史概率
- 相似样本统计保留 90 日未来窗口，避免把未来数据泄漏进条件识别
- 历史日线缓存 6 小时；宏观缓存 10 分钟；ETF 页面缓存 30 分钟，减少公共 API 压力

## 搜索
- 默认扫描 15 个主要资产
- 搜索框不仅支持扫描池资产，也可按 `BTC` / `ETH` / `BTCUSDT` 等格式即时查询其他 USDT 资产
- 如果公开数据不足，明确返回不可分析，不伪造结果

## Render
Root Directory: `crypto_lighthouse`
Build: `pip install -r requirements.txt`
Start: `uvicorn main:app --host 0.0.0.0 --port $PORT`
